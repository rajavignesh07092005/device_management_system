Download the Device Agent

Step 1 — Download the agent

Step 2 — Run it

Double-click device-agent.exe to run it, or open a terminal in the folder where you saved it and run:

device-agent.exe

Windows may show a "Windows protected your PC" warning, since this executable isn't digitally signed. This is expected for a student/personal project — click "More info" → "Run anyway" to proceed.

What happens next

The agent will automatically register itself with the live demo server and appear in the admin dashboard's device list. It will send a heartbeat and check for commands periodically.

Notes

  • This agent connects to a live demo server running on the developer's laptop via a temporary tunnel — it may occasionally be offline.
  • The pre-shared key (PSK) is already built into this executable for demo purposes.
